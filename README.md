# 指间 · 美甲相机

线上入口：https://mikeywa.site/nail/

手机 Safari / Chrome 打开后允许后置相机，手背朝镜头，张开五指。右侧选择短/中/长、九种颜色、纯色/猫眼。右上角“方案”可分别比较关键点/局部边缘微调、平面试色/立体光泽；宽度和甲床位置可校准。效果演示是绘制的示意手，不代表真实跟踪验收。

麦克风按钮开启最长六秒录音，也可再次点按结束；服务端调用豆包录音文件极速识别，组合指令会一次更新多个状态。相机画面留在设备端；语音录音发送到豆包，不在本服务保存。密钥仅保存在服务器 /etc/nail-app.env，未写入前端或代码仓库。当前用户提供的值被上游拒绝：401 / 45000010 / Invalid X-Api-Key，等待实际密钥值后验证。

快门生成不含界面控件的 JPEG，支持时调用系统分享菜单，否则下载。iOS 网页不能静默写入相册，用户可在分享菜单选择存储图像或长按照片。

## 实现边界

MediaPipe Hand Landmarker 的 21 点用于估算五个甲床的位置、朝向与尺寸，并平滑跟踪。模型没有指甲分割类别。局部边缘微调只用画面亮度梯度做有限横向搜索。握拳时抑制部分弯曲手指，遮挡和侧手仍可能有错误覆盖。光泽使用渐变、阴影和亮度采样，猫眼随朝向改变；并非 PBR 环境反射或真实指甲材质重建。没有实现专用指甲分割网络，待实测选择方案后再决定是否采集/标注甲床数据。

## 验证

构建、组合指令/方向计算两项测试通过。线上 390×844 页面无横向溢出，选款、方案对话框和快门照片生成通过，浏览器未发现脚本错误。真人后置相机贴合、侧手、快速移动、物理手机性能和相册保存尚未验收。

## 开发与部署

npm install / npm run dev / npm run build / npm test。

静态模型和 WASM 同域托管，不依赖 CDN。工作线程执行推理。Node 服务监听 127.0.0.1:8796，仅同域来源可以调用语音接口，限制每 IP 每分钟 12 次与 512KB 请求。服务：nail-app.service。独立发布目录：/opt/nail-app/releases，current 符号链接；Nginx 路由：/etc/nginx/snippets/nail-app.conf，实际引用在 sites-enabled/mikeywa.site。20261010-v2 是当前发布，v1 保留。其他原有网站文件未改动。
