# 指间 · 美甲相机

线上入口：https://mikeywa.site/nail/

手机 Safari / Chrome 打开后允许后置相机，手背朝镜头，张开五指。右侧四个 Tab：长短、颜色、质感、款式。款式包含金色闪钻、彩色果冻、经典法式、奶白渐变、玫瑰细闪和琥珀玳瑁；彩色果冻每次点击随机换五种不同颜色。跟踪固定使用第二个“边缘微调”方案；两种旧方案原本共用一个模型。右上角“方案”仍可比较平面试色/立体光泽；宽度和甲床位置可校准。效果演示是绘制的示意手，不代表真实跟踪验收。

页面自动请求麦克风并持续收音；停顿约 0.6 秒或连续说话约 4.5 秒提交一段，识别时继续录音。无需点击语音按钮。浏览器若阻止音频自动启动，触碰页面任意操作后自动恢复。后台暂停收音，返回前台重新申请启动；服务端调用豆包录音文件极速识别，组合指令会一次更新多个状态。相机画面留在设备端；语音录音发送到豆包，不在本服务保存。密钥仅保存在服务器 /etc/nail-app.env，未写入前端或代码仓库。实际密钥替换后，线上测试语音“设置为短款，黑色猫眼”识别成功。

快门生成不含界面控件的 JPEG，支持时调用系统分享菜单，否则下载。iOS 网页不能静默写入相册，用户可在系统分享菜单选择存储图像。快门后无站内预览或保存弹窗。

## 实现边界

MediaPipe Hand Landmarker 的 21 点用于估算五个甲床的位置、朝向与尺寸，并平滑跟踪。模型没有指甲分割类别。局部边缘微调只用画面亮度梯度做有限横向搜索。握拳时抑制部分弯曲手指，遮挡和侧手仍可能有错误覆盖。光泽使用渐变、阴影和亮度采样，猫眼随朝向改变；并非 PBR 环境反射或真实指甲材质重建。没有实现专用指甲分割网络，待实测选择方案后再决定是否采集/标注甲床数据。

## 验证

构建、组合指令/方向计算两项测试通过。线上 390×844 页面无横向溢出，选款、方案对话框和快门照片生成通过，浏览器未发现脚本错误。真人后置相机贴合、侧手、快速移动、物理手机性能和相册保存尚未验收。

## 开发与部署

npm install / npm run dev / npm run build / npm test。

静态模型和 WASM 同域托管，不依赖 CDN。工作线程执行推理。Node 服务监听 127.0.0.1:8796，仅同域来源可以调用语音接口，限制每 IP 每分钟 40 次与 512KB 请求。服务：nail-app.service。独立发布目录：/opt/nail-app/releases，current 符号链接；Nginx 路由：/etc/nginx/snippets/nail-app.conf，实际引用在 sites-enabled/mikeywa.site。20261010-v7 是当前发布，旧版保留。其他原有网站文件未改动。

## 2026-10-10 加载优化与验证

模型在本机运行。原始模型 7,819,105 字节，SIMD WASM 11,453,626 字节。初次网络实测分别 21.86 秒 / 32.75 秒，约 350 KB/s。本地资源加载 133ms，初始化 914ms，模拟相机并行启动另一次初始化为 2871ms；不是物理手机基准。WASM 预压缩传输 3,342,334 字节，减少约 71%。并行下载、版本化一年缓存与读取真实下载字节的百分比进度；99% 为初始化，模型准备完成后隐藏。

七项自动检查通过，含连续两句语音不中断录音、PCM 编码、指令解析、各款纹理与果冻随机配色。手机尺寸无横向溢出，系统分享入口通过浏览器模拟调用验证，无站内弹窗。线上 ASR 已用中文测试语音验证；物理手机持续麦克风与系统分享仍需实测。
