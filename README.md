# 指间 · 美甲相机

线上入口：https://mikeywa.site/nail/

手机 Safari / Chrome 打开后允许后置相机，手背朝镜头，张开五指。右侧四个 Tab：长短、颜色、质感、款式。款式包含金色闪钻、彩色果冻、经典法式、奶白渐变、玫瑰细闪和琥珀玳瑁；彩色果冻每次点击随机换五种不同颜色。跟踪固定使用第二个“边缘微调”方案；两种旧方案原本共用一个模型。右上角“方案”仍可比较平面试色/立体光泽；宽度和甲床位置可校准。效果演示是绘制的示意手，不代表真实跟踪验收。

页面自动请求麦克风并持续收音；停顿约 0.6 秒或连续说话约 4.5 秒提交一段，识别时继续录音。收音按钮仅显示图标，收音时绿色，点击暂停后白色，再点击恢复。浏览器若阻止音频自动启动，触碰页面任意操作后自动恢复。后台暂停收音，返回前台重新申请启动；服务端调用豆包录音文件极速识别，组合指令会一次更新多个状态。相机画面留在设备端；语音录音发送到豆包，不在本服务保存。密钥仅保存在服务器 /etc/nail-app.env，未写入前端或代码仓库。实际密钥替换后，线上测试语音“设置为短款，黑色猫眼”识别成功。

快门生成不含界面控件的 JPEG，支持时调用系统分享菜单，否则下载。iOS 网页不能静默写入相册，用户可在系统分享菜单选择存储图像。快门后无站内预览或保存弹窗。

## 实现边界

MediaPipe Hand Landmarker 的 21 点用于估算五个甲床的位置、朝向与尺寸，并平滑跟踪。模型没有指甲分割类别。局部边缘微调只用画面亮度梯度做有限横向搜索。握拳时抑制部分弯曲手指，遮挡和侧手仍可能有错误覆盖。光泽使用渐变、阴影和亮度采样，猫眼随朝向改变；并非 PBR 环境反射或真实指甲材质重建。没有实现专用指甲分割网络，待实测选择方案后再决定是否采集/标注甲床数据。

## 验证

构建、组合指令/方向计算两项测试通过。线上 390×844 页面无横向溢出，选款、方案对话框和快门照片生成通过，浏览器未发现脚本错误。真人后置相机贴合、侧手、快速移动、物理手机性能和相册保存尚未验收。

## 开发与部署

npm install / npm run dev / npm run build / npm test。

## 语音选款与校准

支持六套款式名称与糖果/果冻、金色、法式、渐变、玫瑰、琥珀/玳瑁等别名。支持“随机给我来一款”“给我推荐一款”，随机选现有预设并避开当前款；“随机再换一个颜色”应用果冻随机五指配色。推荐是随机选款，没有肤色分析。

“甲床再高一点/往上移、低一点/往下移”每次沿指尖方向移动 0.025；“宽一点/窄一点”只调整宽度 0.05；“大一点/小一点”调整甲片整体大小 0.05。同步菜单滑杆，并限制宽度 0.6–1.4、位置 0.15–0.65、整体大小 0.6–1.5。识别规则解析自然表达，未接入通用对话模型；只应用已识别的操作。

下载提示改为纯文字百分比。11 项测试覆盖相对校准、范围、预设与随机指令、暂停/恢复和连续收音。

## 2026-10-11 三维甲片渲染
- 默认 WebGL2：闭合弧面甲片（1968 三角形，含侧壁/底面），透视投影、独立的三维指尖姿态，使用 MediaPipe worldLandmarks 估计指节长度与朝向，掌面法线确定滚转，拇指使用局部平面。平滑三维朝向，背向/折叠时降低误贴。默认甲床位置仍为 0.18。
- 相机低分辨率亮区估计主光方向、色调和环境漫反射，缓慢更新。着色器使用 GGX 高光、菲涅尔边缘反射、宽面光反射与清漆层。光面/哑面/金属/猫眼参数独立；果冻半透明叠加，非真实体积折射。
- 猫眼与细闪颗粒通过固定 UV/seed 的微表面方向反光；没有按时间切换亮点。图案使用缓存的漫反射贴图贴合曲面。实时相机/3D甲片采用浏览器分层合成，避免每帧复制 WebGL 到 2D；快门时同步合并两层到单独的保存画布。
- 共享两档静态网格，最多 32 张 128×192 贴图的 LRU 缓存。五指最多 10 次绘制（含近似接触暗边），高档约 19680 三角形；渲染比例最大 1.25、长边最大 1600；持续掉帧自动减少分辨率与面数。现有跟踪仍在 Worker。WebGL2 不支持或上下文丢失时回退原二维绘制；设置中可选“平面试色”比较。
- 限制：单目手部骨架不是指甲轮廓/甲床分割；视场角为近似值，灯光不是完整 HDR 环境重建，没有精确手指遮挡或真实投影阴影。手机后置相机的贴合、转手和帧率须实机验收。
- 验证：21 项逻辑测试；原生离屏 GPU 编译/链接着色器并渲染光面、哑面、猫眼与侧转图（GLSL ES 300 的着色逻辑使用桌面 GLSL 150 验证）。浏览器 WebGL2 也已实际显示五片甲片、10 次绘制，跟踪模型初始化成功。
