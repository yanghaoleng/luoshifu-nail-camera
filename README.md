# 跟罗师傅快速选款

一个用于美甲选款的网页相机：实时跟踪五根手指，叠加有弧度与建构的 3D 甲片，提供长短、颜色、质感、图案、整套款式与连续语音选款。

- 相机：https://mikeywa.site/nail/
- 观察后台：https://mikeywa.site/nail/admin/

## 使用与边界

手机浏览器允许相机和麦克风后，手背朝向镜头并张开五指。右侧五个 Tab 可搭配选款，右上角可调整甲床位置、甲宽或比较二维/三维渲染。效果演示使用示意手，不代表真实跟踪。快门使用系统分享或文件下载；网页不能保证照片已存入相册。

手部跟踪使用 MediaPipe 骨架与局部轮廓共同估计，非专用指甲分割网络。默认五片共用可信轮廓均值，角度独立跟随手指。WebGL2 使用闭合弧壳、建构厚度与材质光影；复杂背景、遮挡、快速侧转及手机性能仍须实测。

语音采用服务端豆包 ASR；方舟 mini 配置可用时做语义选款，未配置时明确回退基础指令。视频和拍照留在设备上；语音录音发送到识别服务，服务端不保存录音与转写原文。

## 观察后台

按指定 dashboard 技能设计：结论先行、协调指标行、每日趋势、选款偏好表、模型与语音运行质量。支持今天/7天/30天、趋势 Tab、相机/演示分开统计、偏好排序与展开收起、手机布局和减少动态效果。

统计从接入后开始，不回填历史。临时匿名会话按日去重，不等于独立访客或人数。真实试戴是实际相机至少绘制过跟踪甲片；导出只是系统分享返回完成或下载被触发。加载中位耗时只使用完整样本，阶段比例只使用同一会话共同上报的事件。客户端事件用于产品观察，不能视为防伪证据。

仅保存每日匿名阶段、计数、选项分布和耗时；不采集照片、录音、转写原文、精确位置、原始 IP 或浏览器指纹。保留 90 天，数据文件在发布目录之外。测试相机可使用 `?check=1` 跳过事件采集。

## 安全与部署

访问码采用六位数字键盘，服务器校验 scrypt 散列、失败限流；成功后签发随机 HttpOnly / Secure / SameSite=Strict 会话 Cookie。关闭浏览器结束会话，服务器有效期上限 8 小时；退出立即撤销。服务重启会撤销现有后台登录。

**访问码、散列、API 密钥、统计文件都不进入仓库，也不打包进前端。** `.env.example` 仅提供空变量名。真实配置存放服务器环境文件。不要把真实 `.env`、数据备份或日志添加到 Git。

安装与构建：`npm ci`、`npm run dev`、`npm test`、`npm run build`。Vite 构建相机和 `admin/index.html` 两个入口。Node 服务：`node server.mjs`，默认仅监听本机 8796。开发需在服务器环境指定精确的 `NAIL_DEV_ORIGIN`，本地预览才允许登录和上报；本地 HTTP 测试通过显式测试 auth 实例关闭 Secure，生产始终使用 Secure。

环境变量：`DOUBAO_API_KEY`、可选 `ARK_API_KEY` / `ARK_MODEL`、`NAIL_ADMIN_PIN_HASH`（16字节随机盐与64字节 scrypt 派生值，以冒号分隔）、`NAIL_ANALYTICS_SECRET`（独立随机值）、`NAIL_ANALYTICS_FILE`（默认 `/var/lib/nail-app/analytics.json`）。散列通过 `admin-auth.mjs` 的 `hashPin()` 在受保护环境生成，避免把明文写进命令历史或公开构建日志。

参考部署配置见 `ops/`。Nginx 静态提供 `/nail/` 并转发 `/nail/api/`。后台数据必须经 API 登录读取。systemd `StateDirectory=nail-app` 提供独立可写目录；按发布目录与 current 符号链接更新，保留旧版。统计文件写入采用临时文件原子替换，损坏数据不会被自动覆盖。备份与恢复需由运维另外安排，后台没有恢复入口。

## 2026-10-10 加载优化与验证

模型在本机运行。原始模型 7,819,105 字节，SIMD WASM 11,453,626 字节。初次网络实测分别 21.86 秒 / 32.75 秒，约 350 KB/s。本地资源加载 133ms，初始化 914ms，模拟相机并行启动另一次初始化为 2871ms；不是物理手机基准。WASM 预压缩传输 3,342,334 字节，减少约 71%。并行下载、版本化一年缓存与读取真实下载字节的百分比进度；99% 为初始化，模型准备完成后隐藏。

七项自动检查通过，含连续两句语音不中断录音、PCM 编码、指令解析、各款纹理与果冻随机配色。手机尺寸无横向溢出，系统分享入口通过浏览器模拟调用验证，无站内弹窗。线上 ASR 已用中文测试语音验证；物理手机持续麦克风与系统分享仍需实测。

款式参考（类别，不代表复刻品牌产品）：https://www.opi.com/nail-art?page=3 、 https://www.opi.com/en-GB/blog/nail-trends/summers-biggest-nail-trend-jelly-nails

## 语音选款与校准

支持六套款式名称与糖果/果冻、金色、法式、渐变、玫瑰、琥珀/玳瑁等别名。支持“随机给我来一款”“给我推荐一款”，随机选现有预设并避开当前款；“随机再换一个颜色”应用果冻随机五指配色。推荐是随机选款，没有肤色分析。

“甲床再高一点/往上移、低一点/往下移”每次沿指尖方向移动 0.025；“宽一点/窄一点”只调整宽度 0.05；“大一点/小一点”调整甲片整体大小 0.05。同步菜单滑杆，并限制宽度 0.6–1.4、位置 0.15–0.65、整体大小 0.6–1.5。识别规则解析自然表达，未接入通用对话模型；只应用已识别的操作。

下载提示改为纯文字百分比。11 项测试覆盖相对校准、范围、预设与随机指令、暂停/恢复和连续收音。

## 2026-10-11 三维甲片渲染
- 默认 WebGL2：闭合弧面甲片（1968 三角形，含侧壁/底面），透视投影、独立的三维指尖姿态，使用 MediaPipe worldLandmarks 估计指节长度与朝向，掌面法线确定滚转，拇指使用局部平面。平滑三维朝向，背向/折叠时降低误贴。默认甲床位置仍为 0.18。
- 相机低分辨率亮区估计主光方向、色调和环境漫反射，缓慢更新。着色器使用 GGX 高光、菲涅尔边缘反射、宽面光反射与清漆层。光面/哑面/金属/猫眼参数独立；果冻半透明叠加，非真实体积折射。
- 猫眼与细闪颗粒通过固定 UV/seed 的微表面方向反光；没有按时间切换亮点。图案使用缓存的漫反射贴图贴合曲面。实时相机/3D甲片采用浏览器分层合成，避免每帧复制 WebGL 到 2D；快门时同步合并两层到单独的保存画布。
- 共享两档静态网格，最多 32 张 128×192 贴图的 LRU 缓存。五指最多 10 次绘制（含近似接触暗边），高档约 19680 三角形；渲染比例最大 1.25、长边最大 1600；持续掉帧自动减少分辨率与面数。现有跟踪仍在 Worker。WebGL2 不支持或上下文丢失时回退原二维绘制；设置中可选“平面试色”比较。
- 限制：单目手部骨架不是指甲轮廓/甲床分割；视场角为近似值，灯光不是完整 HDR 环境重建，没有精确手指遮挡或真实投影阴影。手机后置相机的贴合、转手和帧率须实机验收。
- 验证：22 项逻辑测试；原生离屏 GPU 编译/链接着色器并渲染光面、哑面、猫眼与侧转图（GLSL ES 300 的着色逻辑使用桌面 GLSL 150 验证）。浏览器 WebGL2 也已实际显示五片甲片、10 次绘制，跟踪模型初始化成功。

法式使用平口圆角曲面，白边仅占甲面长度约 7%，缩略图与 3D 材质保持一致。

## 2026-10-11 共同甲宽与弧面建构
- 五根手指仍独立读取 64×64 旋转局部图像，沿靠近甲床的五条截面找真实轮廓；每 100ms 合并采样一次（320×64），不增加模型下载。
- 取置信度足够且宽度接近的一组（至少三根），用置信度与相似度加权均值估计共同手指直径；明显偏宽/偏窄值不参与。五片甲片共用同一物理宽度，投影仍随各自三维角度变化。默认甲宽为共同直径约 74%，校准上限为共同直径的 88%。
- 在共同手部尺度下平滑均值，单次轮廓更新限制为 2.5%；手靠近或远离时按共同尺度缩放。测量过期后不参与求均值，短暂遮挡保留历史；重新进入画面时重新估计。首次没有三根一致轮廓时共用保守的骨骼中值。
- 甲片的正反两面均为圆柱 C 弧面，底面不再是平板；纵向增加轻微拱形，在约 42% 长度处增加建构厚度，根部、侧缘和自由缘更薄。真实顶点与法线参与现有光影计算，侧转时可看见弧面与厚度；法式平口轮廓与薄白边保留。
- 两档模型仍为 1968 / 832 三角形，不增加绘制次数或逐帧重建网格。仍不是专用指甲分割网络，复杂背景、侧手和遮挡需手机实测。

验证：35 项自动测试，包括最大可信组、偏宽/偏窄异常值、噪声平滑、五指同宽、遮挡保持、距离缩放、圆柱截面、建构厚度、网格闭合、法线与法式平口。

浏览器中用 MediaPipe 官方测试照片 right_hands.jpg 运行真实跟踪模型与相同采样/三维渲染代码：共同估计采用四根手指，五片基础宽度均为 33.87px（实际投影随手指角度不同），五片 10 次绘制、高档 19680 三角形。另用相同灯光与角度对比调整前后的正面/侧转/近侧面模型。完整应用 WebGL2 演示检查无控制台错误。手机实时动态贴合与性能仍需实机验收。
